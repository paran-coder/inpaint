빠르게 시작하기

  1. 열기로 PNG·JPG·WEBP 이미지를 가져오거나, 샘플·새 캔버스로 시작합니다. 파일은 최대 20MB입니다.
  2. 브러시·사각형·올가미로 변경할 부분을 선택합니다.
  3. 작업 방식을 고르고 원하는 내용을 입력합니다. 예: “선택한 위치에 작은 강아지 한 마리를 추가해줘.”
  4. AI가 연결되어 있으면 생성 버튼을 누릅니다. 결과를 비교한 후 결과 적용 또는 폐기를 선택합니다.
  5. 레이어를 선택해 위치·크기를 조절하고 PNG 내보내기로 저장합니다.

AI 연결과 생성

웹 배포판은 이 컴퓨터에서 실행하는 브릿지를 통해 Codex에 요청합니다. 처음 한 번 AI 연결 도움말 → 브릿지 다운로드에서 파일을 받아 압축을 풀고 설치 파일을 실행합니다. 이후에는 편집기의 AI 연결 버튼을 사용합니다. Codex 설치와 본인 ChatGPT 계정 로그인이 필요합니다.

로컬 실행판은 앱 서버에서 Codex 상태를 확인합니다. 연결 설정에서 설치·로그인·이미지 실행 상태를 확인하세요.

웹의 연결은 새로고침이나 다른 탭 이동에도 유지됩니다. 마지막 연결된 편집기 탭을 닫으면 약 30초 후 브릿지를 정리하며, 연결 해제는 해당 탭의 AI 요청을 중단합니다. OS나 브라우저가 앱 실행·로컬 연결 허용을 물으면 직접 허용해야 합니다.

생성하면 필요한 이미지와 요청이 Codex를 통해 OpenAI로 전송되고 구독 사용량이 소모됩니다. 로그인 상태만으로 이미지 도구 제공이나 남은 한도가 보장되지는 않습니다.

생성 품질과 대기 시간

빠르게·균형 있게·정교하게는 도구에 전달하는 요청 선호도입니다. 실제 품질과 생성 시간은 도구가 결정합니다. 생성 중에는 경과 시간을 확인하거나 취소할 수 있습니다.

영역 선택·보호

브러시(B)로 칠하거나, 사각형(M)을 드래그하거나, 올가미(L)로 둘레를 그립니다. 완성된 선택은 점선으로 표시됩니다. 선택 방식에서 새로 선택·더하기·빼기를 바꿀 수 있습니다.

선택 해제 또는 Esc로 선택을 없앱니다. 새로 선택 모드에서 선택 밖을 짧게 클릭해도 해제됩니다. 경계 부드러움은 선택 영역의 안쪽 가장자리를 부드럽게 연결합니다.

보호(P)로 칠한 곳은 수정 대상에서 제외됩니다. 보호 해제로 보호 마스크를 지울 수 있습니다.

작업 방식 선택

방식언제 쓰나요?
대상 추가 · 배경 유지강아지·화분·소품 등을 새로 놓을 때. 투명한 대상과 그림자를 별도 레이어로 추가하며 선택 영역 안에 맞춥니다. 원본 배경은 유지됩니다.
영역 전체 변경 · 배경 포함물체를 지우고 배경으로 채우거나, 벽·바닥·조명까지 변경할 때. 선택한 부분의 배경도 달라질 수 있습니다.
배경과 어우르기직접 불러와 배치한 이미지를 주변 배경과 자연스럽게 합칠 때. 기존 선택 대신 배치 이미지와 주변 합성 범위를 사용합니다.

새 이미지 만들기는 현재 사진의 일부 수정이 아니라 선택한 비율의 새 결과를 만듭니다. 결과를 적용하면 기존 레이어들은 숨겨지고 새 결과 레이어가 추가됩니다. 실행 취소로 이전 상태로 돌아갈 수 있습니다.

추가 대상은 사각형이 아닌 선택 영역에서도 전체가 들어갈 수 있는 내부 공간에 맞춥니다. 선택 모양에 따라 작게 배치될 수 있으니 적용 후 크기를 조절하세요. 불투명한 회색 체크무늬가 그려진 결과는 배경 패턴이 확인되면 브라우저에서 보정한 뒤 미리보기로 표시합니다. 색이 옅거나 회색인 대상의 가장자리와 그림자가 손실될 수 있으므로 반드시 확인하고 적용하세요. 일반 배경이나 분리할 수 없는 결과, 비어 있는 결과는 배경 보호를 위해 적용하지 않습니다.

색감·배경 조화

이미지를 생성하거나 불러온 다음, 배경 위의 대상 레이어를 선택해 위치와 크기를 먼저 맞추세요. 레이어 아래의 보정 버튼을 사용합니다.

색감·경계 맞춤 · 무료

배경의 색·밝기를 참고해 대상 레이어의 색감을 맞추고 가장자리를 약하게 연결합니다. 브라우저 안에서 처리하며 AI 사용량은 소모하지 않습니다. 강도를 조절해 미리보기에서 원본과 비교한 뒤 적용하거나 폐기하세요. 대상의 색을 유지하기 위해 변화량을 제한하므로 극적인 재조명을 하지는 않습니다.

이 기능은 접지 그림자나 반사를 생성하지 않습니다. 150만 픽셀을 넘는 대상은 계산량을 줄이기 위해 경계 보정을 생략하고 색감만 맞춥니다. 보호 영역과 투명도는 보존합니다.

AI로 어우르기 · 추가 사용량

AI로 어우르기는 합성 설정을 엽니다. 이 버튼만 눌러서는 생성하지 않습니다. 요청과 주변 합성 범위를 확인하고 배경과 어우르기를 누르면 Codex에 추가 요청을 보냅니다. 대상의 위치·크기·형태를 유지하면서 조명·접지 그림자·약한 반사를 배경과 맞추도록 요청합니다.

결과는 대상과 주변 배경을 함께 담은 별도 보정 레이어입니다. 범위 밖과 보호 영역은 변경하지 않으며 기존 레이어를 보관합니다. 보정 레이어 자체는 이동·크기 조절하지 않습니다. 원본 대상 레이어를 이동하거나 삭제하면 기존 보정 레이어를 자동으로 숨깁니다. 새 위치에서 다시 AI로 어우르기를 실행하세요. Ctrl+Z로 이동과 숨김을 함께 되돌릴 수 있습니다.

미리보기와 보정 레이어도 자동 저장·복구됩니다. 실제 생성 결과의 조명·그림자·정체성은 모델에 따라 달라지므로 적용 전 비교하세요.

색상 일치와 경계 연결은 PhotoCraft 소스를 바탕으로 이식·수정했습니다. 출처·라이선스

레이어와 삭제

+는 빈 레이어를 만듭니다. 해당 레이어에서 이미지 불러오기를 누르면 이미지를 넣을 수 있습니다. 목록을 클릭하면 그 레이어를 선택하고 이동 도구로 전환합니다. 눈 모양 버튼은 표시·숨기기, 레이어 행을 드래그해 삽입선 위치에 놓으면 쌓이는 순서가 바뀝니다. Alt+위·아래 방향키로도 순서를 바꿀 수 있습니다.

휴지통 버튼은 선택 영역이 있어도 레이어 전체를 삭제합니다. 레이어 목록에 초점을 둔 상태에서 Delete를 눌러도 같습니다. 레이어를 휴지통으로 드래그해도 전체가 삭제됩니다. 캔버스에서 Delete를 누르면 선택 영역의 픽셀을 지우며, 선택이 없으면 활성 레이어를 삭제합니다.

잘못 삭제했다면 Ctrl+Z로 되돌리세요. 선택 영역 지우기는 현재 활성 레이어에 적용됩니다.

이동·크기 조절

  1. 오른쪽 목록에서 가져온 이미지 또는 적용한 AI 결과 레이어를 선택합니다.
  2. 이미지의 조절 테두리가 표시됩니다. 내부를 드래그하면 이동하고 모서리를 드래그하면 비율을 유지하며 크기가 바뀝니다.
  3. 정확한 크기는 오른쪽 이미지 크기 · 위치의 너비·높이를 입력합니다. 단위는 px이며 1~8192 범위입니다.
  4. 가로·세로 비율 유지를 끄면 너비와 높이를 각각 변경할 수 있습니다. 이 설정은 숫자 입력에 적용됩니다. 모서리 드래그는 비율을 유지합니다.

X·Y는 위치, 회전은 각도, 불투명도는 비치는 정도입니다. 이 조작은 선택한 이미지 레이어의 크기를 바꿉니다. 전체 작업 영역의 크기는 바뀌지 않으며, 바깥으로 나간 부분은 PNG 내보내기에서 잘립니다. 전체 작업 크기는 새 캔버스 생성 시 지정합니다.

AI 미리보기 상태에서는 먼저 결과 적용을 눌러 편집 가능한 레이어로 만드세요. 화면 확대·축소는 이미지 자체의 크기를 변경하지 않습니다.

배경 제거

단색 배경은 테두리에 연결된 비슷한 색을 즉시 지웁니다. 허용 오차를 높이면 더 넓은 색 범위를 제거합니다. 인물 AI는 최초 약 26MB 모델과 실행 라이브러리를 다운로드하며 인물에 적합합니다. 배경 제거는 브라우저 안에서 처리합니다.

첨부할 때 자동 제거를 켜면 이미지를 불러올 때 제거합니다. 수동으로는 지우기(E)·복원(R) 브러시 또는 선택 지우기·선택 복원을 사용합니다. 복원은 현재 레이어가 보관한 원본을 기준으로 합니다.

저장·내보내기

작업은 현재 브라우저에 자동 저장됩니다. 상태가 저장 완료로 바뀌었는지 확인하세요. 다음 방문 시 저장된 작업 복구로 레이어·선택·보호 영역과 대기 중인 생성 결과를 복원할 수 있습니다. 이전 실행 취소 이력은 복구되지 않습니다.

브라우저 저장소를 지우거나 다른 기기·브라우저로 이동하면 자동 저장 작업을 사용할 수 없습니다. 완성 이미지는 PNG 내보내기로 별도 저장하세요. PNG는 보이는 레이어를 합친 이미지이며 편집 가능한 레이어 파일은 아닙니다.

문제 해결

레이어가 지워지지 않아요

오른쪽에서 레이어를 선택한 뒤 레이어 삭제 버튼을 사용하세요. 캔버스에서 선택 영역이 있으면 Delete는 영역 안의 픽셀을 지웁니다.

크기 조절 테두리가 안 보여요

결과 미리보기라면 먼저 적용하고, 레이어 목록에서 표시된 레이어를 선택하세요. 이동 도구(V)에서 조절 테두리가 나타납니다. 이미지가 화면보다 크면 화면 맞춤을 사용하거나 너비·높이를 직접 입력하세요.

AI 연결이 안 되거나 생성에 실패해요

연결 도움말에서 Codex 설치와 로그인을 확인하세요. 웹에서는 브릿지가 설치된 같은 컴퓨터를 사용하고 브라우저의 로컬 연결 허용을 확인합니다. 한도·계정 도구 제공·네트워크 또는 생성 결과 형식 때문에 실패할 수 있으므로 표시되는 오류를 확인하세요. 실패 후에는 새 요청이므로 사용량이 추가될 수 있습니다.
